# cang-jie 固件白名单 —— 每行：<sha256(/usr/bin/xochitl)>  <人读标签>
#
# 【为什么用 sha256 而非版本字符串】设备端 install.sh 的"固件门"逐字节比对
# /usr/bin/xochitl 的 sha256（rmtool fail-safe 范式，见中文化白皮书 §4.3）。
# 比 /etc/version 版本号更严：qmldiff 注入靠 xochitl 的 QML 资源布局，同一版本号
# 的热修都可能挪动布局；哈希对上才保证"本包在这颗二进制上验证过、注入定位可靠"。
#
# 【新老设备通用】同一固件的任意设备，其 /usr/bin/xochitl 逐字节相同 → sha256 相同
# → 白名单命中 → 一键装。装错固件（哈希不在表内）默认拒绝，避免 qmd 定位错位崩溃；
# 确要装用 `install.sh --force`（会自动把当前哈希追加进本表，并交给设备端多层
# fail-safe 兜底：.so 内部特征码自定位 + qrr 崩溃自愈 + ExecStartPre 摘链裸启）。
#
# 【维护】OTA 到新固件、真机验证注入无误后，把新哈希加一行即可让本包认它为"版本对"。
# 下面这行的哈希 = rmfw/xochitl_3.28.0.169.bin 提取件，已于 2026-08-28 与设备实测

#   /etc/version=20260806095513）。提取件与在盘文件同源，固件门可直接命中。
