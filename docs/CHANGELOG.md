### 09-21

- **appload 升级到官方 0.6.0（原生支持 3.28，另加 3.29）**：侧栏 KOReader / WeRead 入口不再依赖我们之前的"等长回填补丁"，那套补丁工具已删除；`vellum add/upgrade appload` 拿到的就是可用版本。已知变化（据上游行为推断，未在真机验证）：0.6.0 的实体键（左/主页/右）在 KOReader 里可能不响应（只影响外接键盘）。**升级 appload 后请整机重启，不要 `systemctl restart xochitl`**（旧进程退出时会崩溃并触发一次整机重启）。
- **新增实验室开关「漫画页边距最小化」（默认关，仅对纯图漫画 EPUB 生效）**：漫画在 xochitl 里被画成固定"图片框"，旧补白让图片只有约 260pt 宽（页宽 303pt）、左右留白 20 / 23pt。打开开关后：之后**优化**的漫画页补白成更宽的页框，且漫画**加入 xochitl** 后你**首次打开**那本书时，阅读器自己会把页边距设为 1（几乎为 0，用的是阅读器自己的设置接口，不是改文件；之后你在「文字设置」里改回去也不会被覆盖）。真机端到端：图片宽约 302pt、左右留白约 0.3 / 0.7pt，宽度 +16%。**只对开关打开之后新优化、新加入的漫画生效**；已经在设备里的旧漫画需从原始文件重新优化再加入。文字书、PDF 完全不受影响；关着时一切与以前一致。详见 bookconv 白皮书 §20。
- **「漫画页边距最小化」现在也支持带文字页的漫画**（如《镖人》有版权页、前情提要、章节标题页）：此前只放行整本零文字的漫画，带文字页的被静默排除。现在优化时会给纯文字页自动留出左右边距（图片页仍满宽），加入后首次打开同样生效。**已经优化过的这类漫画要从原始文件重新优化**才会带上。同时修了一个让漫画页图片在边距 1 下仍被吃掉约 20pt 的问题（Calibre 转的书每页 body 上的样式类所致）：现在图片页真正铺到左 0.3 / 右 0.7pt，宽度 302pt。图片铺满后，"图 + 标题/说明"页里的文字会被挤到单独一页，这些文字（说明、靠左的标题）现在也会自动留出左右边距，不再贴着屏幕边缘。
- **「电池刺客」开关从实验室移到「系统增强」标签**（用户要求）。
- **每页尺寸统一**：漫画补白的容差收紧，不再出现个别页宽了 / 窄了几个点的情况（新页框下）。
- **升级后需要重启阅读器一次**（`systemctl restart xochitl`）才能加载新的页边距代理。

### 09-20

- **漫画「优化」保持 EPUB，不再转 PDF**（取代 09-19 的做法）：转 PDF 虽然左右留白更小，但一图一页会丢漫画里夹带的文字页；EPUB 的固定内边距是 xochitl 渲染引擎的硬限制，接受它换取"不改变书的内容"。EPUB 漫画图片改为"解码一次、裁边、缩放一次、编码一次"，灰度保持，画质与速度都更好。
- **书名统一规范**：入库和优化时整理成 `书名 - 02卷`（数字在前）；去掉下载站文件名里 `-- 作者 -- … -- hash` 这类尾巴与"[完]"标记。
- **突破 xochitl 约 100MB 的上传上限**：>90MB 的 EPUB/PDF 走"占位 + 磁盘替换"通道，不再分卷（真机验证 PDF 154MB/349 页、EPUB 153MB 均可打开；上限 1GiB）。
- **批量队列**：在母版库勾选后一次排队，由网关顺序逐本执行「优化 / 加入 xochitl / 加入 KOReader」；关掉浏览器、换设备重开、网关重启后都会接着跑；可随时"全部中止"（EPUB 优化与按卷拆分投递能中途停）。
- **母版库页重做**：行内只显示书名/类型/大小/状态/进度，只有处理中才有"停止"按钮；所有操作在勾选后的底部批量栏（优化 / 加入 xochitl / 加入 KOReader / 删除 / 清除）；"加入位置"是两个常驻下拉，可直接"＋新建文件夹"；搜索带下拉建议；真分页；PC 与手机同一套单列布局；筛选四项统一带数量。
- **优化提速**：图片并行处理（有内存预算），设备上一本 350 页漫画 285 秒 → 148 秒，产物字节不变。
- **封面修复**：修好部分书在设备上没有封面缩略图的问题；新增无损补封面小工具 `cover-fix`。
- **漫画 EPUB 缺目录修复**：纯图片书没有目录时按每 20 页分段生成。
- **省电**：母版库列表判定加缓存（CPU 约降 70 倍，批量优化时不再持续耗电）；`wifi-watch` 链路正常时零 fork（子进程 CPU 约降 9 倍），并修了"每次启动都白白断线重连 WiFi"的判据错误。
- **清洗层**：删除指向书内不存在文件的 `<img>` 和死 `@font-face` 来源（减少 xochitl 日志噪声，正文逐字不变）。
- **安装/卸载脚本重构**：`install-all.sh` / `uninstall-all.sh` 共用同一张步骤表，新增 `wifi-watch` 步骤；覆盖前先备份进 `cangjie-backups/`（保留最近 5 份）；`--force` 只追加到本机 `firmware-allowlist.local.txt`；重启 xochitl 改为“xovi 已生效走 `systemctl restart xochitl`，没生效才 `xovi/start`”并先提示留 5 秒宽限（修复重跑安装会让 xochitl 崩溃并整机自动重启的事故）；battop 明确不随开机自启；网关密码不再拼命令行；新增不碰真机的本机模拟测试。
- **可靠性**：后台任务 panic 只影响这一本、不再摔掉整个服务；服务重启后被中断的"处理中"记录自动修正为失败并清理半成品；新书不再继承同名旧书的"已加入"记录。
- 渲染徽章统一：直接投入（含大文件通道）的书也有渲染记录，EPUB 打开后自动显示真页数。
